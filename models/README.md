# Model Artifacts

This folder stores trained machine learning models generated by the training scripts.

## Why models are not in Git

The trained `.pkl` files are approximately **1 GB** in total, and individual files exceed GitHub's **100 MB** per-file limit. They are listed in `.gitignore`.

## How to generate models

From the project root:

```bash
cd src
python train_regression.py
python train_classification.py
python regression_analysis.py
```

## Expected files after training

| File | Description |
|------|-------------|
| `best_model.pkl` | Best regression model (Random Forest) |
| `best_classifier.pkl` | Best classification model (Random Forest) |
| `label_encoder.pkl` | AQI category label encoder |
| `linear_regression.pkl` | Linear regression pipeline |
| `random_forest.pkl` | Random Forest regressor pipeline |
| `xgboost.pkl` | XGBoost regressor pipeline |
| `logistic_regression_classifier.pkl` | Logistic regression classifier |
| `random_forest_classifier.pkl` | Random Forest classifier |
| `xgboost_classifier.pkl` | XGBoost classifier |

Evaluation charts and CSV reports are saved to the `outputs/` folder.
